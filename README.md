# productforge-stack.github.io

Portfolio site for Tim Duffy, Senior Quality Engineer. Live at https://productforge-stack.github.io/

- `index.html`: overview for recruiters and hiring managers
- `work/pepminder/`: PepMinder Android case study
- `assets/`: stylesheet and images

Plain HTML and CSS with no build step and no trackers. Push to `main` and GitHub Pages deploys it.

Every figure on the site comes from the resume or from the PepMinder repository (`docs/features/FULL_REGRESSION_TEST_PLAN.md`, `codemagic.yaml`). Update both together.
